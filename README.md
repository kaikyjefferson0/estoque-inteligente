# Sistema de Controle de Estoque Inteligente

API para gerenciamento inteligente de estoque.

## Objetivo

Sistema desenvolvido para gerenciamento de produtos,
fornecedores, usuários e movimentações de estoque.

## Funcionalidades

- Cadastro de produtos
- Cadastro de fornecedores
- Cadastro de usuários
- Controle de entradas
- Controle de saídas
- Ajustes de estoque
- Controle de lotes
- Controle de validade
- Alertas de estoque baixo
- Alertas de vencimento
- Histórico de movimentações
- Autenticação
- Controle de permissões
- Código de barras

## Tecnologias

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- psycopg 3
- Alembic
- Argon2
- JWT
- Uvicorn
